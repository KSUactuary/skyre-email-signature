New Outlook · Outlook on the web

  1. Click Copy signature above.
  2. Outlook → Settings (⚙) → Account → Signatures → + New signature, name it “Sky Re”.
  3. Paste with Ctrl+V, set it as default for new messages and replies, then Save.
اضغط زر النسخ الأول، ثم في أوتلوك: الإعدادات ← الحساب ← التوقيعات ← توقيع جديد ← الصق ← حفظ.

Classic Outlook for Windows

  1. Click Copy for classic Outlook.
  2. Outlook → File → Options → Mail → Signatures… → New.
  3. Paste with Ctrl+V, choose it for new messages and replies, then OK.
افتح هذه الصفحة من نفس مجلد ملف الشريط واضغط زر النسخ الثاني، ثم في أوتلوك: ملف ← خيارات ← البريد ← التوقيعات ← جديد ← الصق.

Gmail

  1. Click Copy for Gmail above.
  2. Gmail → Settings (⚙) → See all settings → General → Signature → Create new, name it “Sky Re”, then paste with Ctrl+V.
  3. Select the gold line [ Sky Re banner … ] and delete it. In the same spot click Insert image → Upload → choose Sky Re - Signature Banner.gif, then click the image and pick Original size.
  4. Under Signature defaults choose “Sky Re” for new emails and replies, then Save Changes at the bottom of the page.
اضغط زر النسخ الثالث، ثم في جيميل: الإعدادات ← عرض كل الإعدادات ← عام ← التوقيع ← إنشاء جديد ← الصق. بعدها احذف السطر الذهبي وأدرج صورة الشريط من زر «إدراج صورة» ← تحميل، واختر «الحجم الأصلي»، ثم احفظ التغييرات.

Good to know

  1. Don’t resize the banner in the editor. It must stay 600 × 130.
  2. Classic Outlook shows the banner’s first frame (the full logo). Everywhere else it animates.
  3. Works with Outlook in Arabic: the signature always stays left-to-right.
  4. If the banner is missing after pasting, try the other copy button, or insert Sky Re - Signature Banner.gif with the editor’s picture button.
